# Documentación en 32 idiomas

Guías de uso en Markdown; el archivo canónico de instrucciones sigue siendo [SKILL.md](../../security-review/SKILL.md). Las guías resumen instalación, revisión, desarrollo, tests y estudio. No son 32 copias del protocolo completo.

Selección: primeras 32 entradas por hablantes totales (L1 + L2) de la tabla Ethnologue 2026 reproducida en [Wikipedia, revisión consultada](https://en.wikipedia.org/w/index.php?title=List_of_languages_by_total_number_of_speakers&oldid=1383412139), consultada el 2026-11-05. El acceso directo a [Ethnologue](https://www.ethnologue.com/insights/ethnologue200/) devolvió HTTP 403; la clasificación se verificó en esa fuente secundaria. No se agruparon las variedades de chino o árabe. Los rangos dependen de cómo se defina cada lengua y de las estimaciones de segunda lengua.

Las traducciones fueron generadas por IA y no tienen revisión independiente de hablantes nativos. Los controles automáticos comprueban cantidad, enlaces y estructura, no calidad lingüística ni comportamiento del agente en los 32 idiomas. Se usa escritura simplificada para mandarín, tradicional para cantonés, una aproximación escrita de shanghainés para wu y Shahmukhi para panyabí occidental.
